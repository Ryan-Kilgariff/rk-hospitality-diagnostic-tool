# RK Hospitality Diagnostic Tool

A Python terminal-based diagonostic system for hospitality
operators.

## Features

- Run operational audits
- Score business risk
- Generate reccomendations
- Create 4-week action plans
- Save TXT reports
- Generate PDF reports
- Search previous reports
- Read previous reports
- Delete reports with backup
- Add follow-up notes

## Built with

- Python 
- Reportlab
- Colorama
- JSON
- File handling

## Purpose

This project was built to practice Python while devloping a practical hospitality operations tool.
